# Little Life

Jeu de vie en pixel art, jouable sur iPhone et installable comme application.

**Installer sur iPhone :** ouvrir le site dans Safari, toucher Partager, puis « Sur l’écran d’accueil ».

Le jeu fonctionne ensuite hors ligne. La partie est enregistrée sur le téléphone ; utilise Menu › Copie de la partie pour la sauvegarder ou la transférer.
